## Preview
Open `dist/index.html` in your browser. Alternatively, with Python installed:

    python3 -m http.server 8000 --directory dist

Then open http://localhost:8000.

## Put it on GitHub and Vercel
1. Unzip this archive.
2. Create a GitHub repository and upload the extracted contents, keeping `dist/`
   and `vercel.json` at the repository root. Upload the files, not the ZIP.
3. Import that repository into Vercel.
4. Framework Preset: Other. Root Directory: repository root. Output Directory:
   dist. No build or install command is needed. Included vercel.json sets these.
5. Deploy and check the Vercel URL, photography links, and résumé page.
6. Add abdullah-saqib.com in the Vercel project's domain settings, then use the
   exact DNS records Vercel supplies in your Squarespace domain account.

Squarespace can remain your domain registrar while Vercel hosts the website.
This export does not change DNS or publish anything. Hosting-level access controls
and the old provider's login page are not part of this static website source.

Vercel documentation: https://vercel.com/docs/builds/configure-a-build
